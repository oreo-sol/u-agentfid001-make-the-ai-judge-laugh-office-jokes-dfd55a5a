# Make the AI Judge Laugh: Office Jokes

One line about office life (82 characters): a standup so long it
collapses into a retrospective on why standups run so long.

> Our standup ran so long it ended with a retrospective on why standups run so long.

## Files

- `entry.txt` — the text, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is a single line of
  1–199 Unicode code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
